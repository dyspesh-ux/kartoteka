# Дизайн (короткий): отчёт «СКУД: опоздания» и его рассылка

Дата: 2026-11-25
Статус: на согласовании

## Зачем

Руководству нужен ежедневный контроль дисциплины по СКУД: кто пришёл позже начала дня.
График у всех один: 9:00–18:00, 5/2. Порог должен настраиваться фильтром («покажи, кто
после 9:10 / 9:30»). Отчёт должен уметь уходить по почте по расписанию.

## Подходы

Выбран вариант **A — отдельный отчёт** (решение заказчика, 2026-11-25): новый Script
Report «СКУД: опоздания». Альтернатива B (фильтры порога в существующий «СКУД: приходы и
уходы») отвергнута: форма перегружается, для рассылки всё равно нужен отдельный набор
фильтров.

## Решения

- **Отчёт `ZKBio Latecomers`** (Script Report, модуль ZKBio, workspace «СКУД»). Фильтры:
  `date_from`, `date_to` (необязательные; **по умолчанию — вчера** — это позволяет штатному
  Auto Email Report слать отчёт за вчера, т.к. его фильтры статичны), `threshold`
  (Time, по умолчанию 09:00), `department` (Link HR Department), `only_late`
  (Check, default 1 — смысл отчёта; сняв, видно всех), `show_absent` (Check, default 0),
  `show_weekends` (Check, default 0).
- Строки: сотрудник, день, первое событие, **опоздание, мин** (first_event − threshold;
  пусто, если не опоздал), последнее событие, точки прохода, отсутствие.
  Исключения — как в `ZKBio Attendance`: уволенные всегда, отсутствующие (`HR Absence`)
  до флага; сб/вс скрыты до флага `show_weekends` (WEEKDAY(day) <= 4).
- Реализация — переиспользование SQL/хелперов `zkbio_attendance` (общая выборка день×
  сотрудник); `ZKBio Attendance` получает те же флаги `show_weekends` и необязательные
  даты (default вчера) для симметрии.
- **Рассылка** — без кода: штатный Auto Email Report (README: пошагово — отчёт
  `ZKBio Latecomers`, фильтры пустые (сработают умолчания: вчера, 09:00, только
  опоздавшие), Daily, получатели, формат по вкусу). Тесты — `test_zkbio.py` (порог,
  минуты опоздания, выходные, отсутствия, умолчание «вчера», only_late).
- **Кодировка отправителя**: не код (Frappe шлёт корректный RFC2047, ломает почтовый
  шлюз). Workaround — имя отправителя в Email Account латиницей; зафиксировать в README.

## Ограничения (принятые)

- Праздничные дни не учитываются (календаря в реестре нет): в праздник все «опоздают» —
  лечится выбором периода/снятием only_late.
- Опоздание считается от одного порога для всех; индивидуальных графиков нет.
